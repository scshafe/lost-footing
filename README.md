# Lost Footing

A keyboard survival fighter for the browser. Players share a stage built from
crumbling platforms and never hit each other: they win by placing obstacles,
breaking platforms and steering hazards so that the others lose their
footing. The owner's brief is [docs/brief.md](docs/brief.md).

## Run it locally

```sh
./scripts/serve        # then open http://localhost:8080
```

## Build and test

```sh
./scripts/verify-linux
```

The repository's one verify command (`dev.toml [verify]`). Needs Node.js 24.
